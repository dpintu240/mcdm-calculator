Step 1 — Define the Decision Matrix

Specify the number of alternatives (observations or locations) and evaluation criteria. The decision matrix will contain one row per alternative and one column per criterion.

Allowed: 2–500 alternatives and 2–30 criteria.

Step 1B — Define Labels and Criterion Types

Provide unique criterion names and specify whether higher values are preferable (benefit) or lower values are preferable (cost).

Step 2 — Decision Matrix

Enter non-negative numerical observations for each alternative and criterion. Decimal values are accepted. Do not leave any cell blank.

Normalization approach: Each criterion is first transformed using min–max normalization according to its benefit or cost type. The normalized values are then converted into proportions for entropy calculation. For a constant criterion, all normalized values are set to 1, resulting in zero information utility and a zero entropy weight.

Step 3 — Shannon Entropy Analysis Report

The entropy method derives objective criterion weights from the dispersion of normalized observations across alternatives.

Manual Shannon Entropy Calculation Guide

The following numbered procedure explains the equations implemented in this application. The same calculations can be reproduced manually using the decision matrix.

Notation: \(x_{ij}\) is the observed value for alternative \(i\) and criterion \(j\); \(m\) is the number of alternatives; \(n\) is the number of criteria; \(z_{ij}\) is the normalized value; and \(p_{ij}\) is the proportion.
  1. Construct the decision matrix.
    \(X=[x_{ij}]_{m\\times n}\)
    Rows represent alternatives and columns represent criteria. All observations must be non-negative.
  2. Normalize benefit criteria. For a criterion where higher values are preferable:
    \(z_{ij}=\\frac{x_{ij}-\\min_i(x_{ij})}{\\max_i(x_{ij})-\\min_i(x_{ij})}\)
  3. Normalize cost criteria. For a criterion where lower values are preferable:
    \(z_{ij}=\\frac{\\max_i(x_{ij})-x_{ij}}{\\max_i(x_{ij})-\\min_i(x_{ij})}\)
  4. Calculate the proportion matrix. Sum each normalized criterion column and divide each value by its column sum:
    \(p_{ij}=\\frac{z_{ij}}{\\sum_{i=1}^{m}z_{ij}}\)
    Thus, \(\\sum_i p_{ij}=1\) for each non-constant criterion with a positive normalized sum.
  5. Calculate the entropy constant.
    \(k=\\frac{1}{\\ln(m)}\)
  6. Calculate the entropy value for each criterion.
    \(e_j=-k\\sum_{i=1}^{m}p_{ij}\\ln(p_{ij})\)
    Use the convention \(0\\ln(0)=0\).
  7. Calculate the degree of diversification (information utility).
    \(d_j=1-e_j\)
  8. Calculate the objective entropy weight.
    \(w_j=\\frac{d_j}{\\sum_{j=1}^{n}d_j}\)
    The weights sum to one: \(\\sum_j w_j=1\).
  9. Rank the criteria. Sort the criteria in descending order of entropy weight. The largest weight receives Rank 1.
Methodological note: This application uses min–max normalization with criterion direction (benefit/cost) specified by the user, followed by column-wise proportion normalization and Shannon entropy weighting. Some studies use different normalization schemes; report the exact scheme used. If a criterion is constant across all alternatives, it contains no discriminatory information and is assigned zero entropy weight. If all criteria have zero information utility, normalized weights cannot be meaningfully derived.
