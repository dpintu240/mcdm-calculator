Manual Fuzzy AHP Calculation Guide — Buckley Method

The following numbered procedure describes the Buckley fuzzy geometric mean method implemented in this application. Each step can be reproduced manually using the fuzzy pairwise comparison matrix.

Notation: \(\\tilde A=[\\tilde a_{ij}]\) denotes the fuzzy pairwise comparison matrix; \(n\) is the number of criteria; and a triangular fuzzy number is represented by \((l,m,u)\), where \(l\\leq m\\leq u\).
  1. Construct the fuzzy pairwise comparison matrix.
    \\(\\tilde A=[\\tilde a_{ij}],\\quad \\tilde a_{ii}=(1,1,1)\\)
    For reciprocal judgments:
    \\(\\tilde a_{ji}=\\tilde a_{ij}^{-1}=(1/u_{ij},\\;1/m_{ij},\\;1/l_{ij})\\)
  2. Calculate the fuzzy geometric mean for each criterion.
    \\(\\tilde r_i=\\left(\\prod_{j=1}^{n}\\tilde a_{ij}\\right)^{1/n}\\)
    For TFNs, perform multiplication and the nth root component-wise:
    \\(\\tilde r_i=(\\prod_j l_{ij})^{1/n},\\;(\\prod_j m_{ij})^{1/n},\\;(\\prod_j u_{ij})^{1/n}\\)
  3. Sum the fuzzy geometric means.
    \\(\\sum_{i=1}^{n}\\tilde r_i=(\\sum_i r_{il},\\;\\sum_i r_{im},\\;\\sum_i r_{iu})\\)
  4. Calculate the inverse of the sum.
    \\((\\sum_i\\tilde r_i)^{-1}=(1/\\sum_i r_{iu},\\;1/\\sum_i r_{im},\\;1/\\sum_i r_{il})\\)
  5. Calculate the normalized fuzzy weights (Buckley fuzzy weights).
    \\(\\tilde w_i=\\tilde r_i\\otimes(\\sum_{k=1}^{n}\\tilde r_k)^{-1}\\)
    Thus:
    \\(\\tilde w_i=(r_{il}/R_u,\\;r_{im}/R_m,\\;r_{iu}/R_l)\\)
    where \(R_l=\\sum r_{kl}\), \(R_m=\\sum r_{km}\), and \(R_u=\\sum r_{ku}\).
  6. Defuzzify each fuzzy weight using the centroid method.
    \\(D_i=(w_{il}+w_{im}+w_{iu})/3\\)
  7. Normalize the defuzzified weights.
    \\(W_i=D_i/\\sum_{k=1}^{n}D_k\\)
    The normalized crisp weights should sum to 1:
    \\(\\sum_{i=1}^{n}W_i=1\\)
  8. Defuzzify the comparison matrix for a consistency diagnostic.
    \\(a_{ij}^{*}=(l_{ij}+m_{ij}+u_{ij})/3\\)
    Use this reciprocal crisp matrix and the normalized crisp weight vector \(W\) for the consistency calculations below.
  9. Calculate the weighted-sum vector.
    \\(WS_i=\\sum_{j=1}^{n}a_{ij}^{*}W_j\\)
  10. Calculate the consistency vector.
    \\(CV_i=WS_i/W_i\\)
  11. Estimate the maximum eigenvalue.
    \\(\\lambda_{max}=\\frac{1}{n}\\sum_{i=1}^{n}CV_i\\)
  12. Calculate the Consistency Index.
    \\(CI=\\frac{\\lambda_{max}-n}{n-1}\\)
  13. Obtain the Random Index and calculate the Consistency Ratio.
    \\(CR=CI/RI\\)
    Use the Random Index table below. For a 2 × 2 matrix, RI is zero and CR is conventionally reported as zero.
  14. Evaluate consistency and rank the criteria.
    A CR of 0.10 or less is generally treated as acceptable for this defuzzified-matrix diagnostic. Rank criteria in descending order of normalized crisp weight \(W_i\); the largest weight receives Rank 1.
