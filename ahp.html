Manual AHP Calculation Guide

This guide presents the calculation procedure and equations used in the application. You can reproduce the analysis manually using the pairwise comparison matrix.

Notation
\(A=[a_{ij}]\) is the pairwise comparison matrix; \(n\) is the number of criteria; \(w_i\) is the priority weight of criterion \(i\); and \(RI\) is the Random Index.
  1. Construct the pairwise comparison matrix.
    Enter the relative importance of each pair of criteria using Saaty's scale. The diagonal elements are equal to 1, and reciprocal elements satisfy:
    \(a_{ii}=1\)
    \(a_{ji}=1/a_{ij}\)
  2. Calculate the sum of each column.
    Add all entries in each column \(j\):
    \(S_j=\sum_{i=1}^{n}a_{ij}\)
  3. Normalize the pairwise comparison matrix.
    Divide each element by the sum of its corresponding column:
    \(b_{ij}=a_{ij}/S_j\)
  4. Calculate the priority vector (criteria weights).
    Calculate the arithmetic mean of each row of the normalized matrix:
    \(w_i=\frac{1}{n}\sum_{j=1}^{n}b_{ij}\)
    The weights should sum to approximately 1:
    \(\sum_{i=1}^{n}w_i=1\)
  5. Calculate the weighted-sum vector.
    Multiply the original comparison matrix by the priority vector:
    \(WS_i=\sum_{j=1}^{n}a_{ij}w_j\)
  6. Calculate the consistency vector.
    Divide each weighted-sum value by its corresponding priority weight:
    \(CV_i=WS_i/w_i\)
  7. Estimate the maximum eigenvalue.
    Calculate the arithmetic mean of the consistency vector:
    \(\\lambda_{max}=\frac{1}{n}\sum_{i=1}^{n}CV_i\)
  8. Calculate the Consistency Index (CI).
    \(CI=\frac{\\lambda_{max}-n}{n-1}\)
  9. Identify the Random Index (RI).
    Use the standard Saaty Random Index corresponding to the matrix order \(n\):

  1. Calculate the Consistency Ratio (CR).
    \(CR=CI/RI\)
    For a 2 × 2 matrix, RI is zero; the consistency ratio is conventionally treated as 0.
  2. Evaluate the consistency of the judgments.
    A CR value of 0.10 or less is generally considered acceptable. If CR exceeds 0.10, review and revise the pairwise judgments where appropriate.
  3. Rank the criteria.
    Arrange the criteria in descending order of their priority weights. The criterion with the highest weight receives Rank 1.
Methodological note: This application estimates the priority vector using the normalized-column arithmetic mean method. The maximum eigenvalue and consistency statistics are approximated from that priority vector. Small numerical differences may occur compared with software that computes the principal eigenvector directly.
