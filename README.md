# 🌍 Spatial MCDM Tools
### A Web-Based Decision Support Toolkit for Geospatial Research

**Spatial MCDM Tools** is a web-based Multi-Criteria Decision-Making (MCDM) toolkit developed to support spatial analysis, GIS-based modeling, and natural hazard susceptibility assessment. The platform provides three widely used criteria-weighting techniques to derive weights for multi-criteria spatial decision-making.

The toolkit is designed to simplify the weighting process, support systematic research analysis, and provide useful inputs for GIS-based spatial modeling.

## 📌 Available Methods

### 1. Analytical Hierarchy Process (AHP)
A widely used subjective weighting technique based on pairwise comparisons of decision criteria.

**Key Features:**
- Pairwise comparison matrix construction.
- Calculation of priority vectors and normalized criteria weights.
- Consistency Index (CI) and Consistency Ratio (CR) calculation.
- Evaluation of consistency in expert judgments.

### 2. Fuzzy Analytical Hierarchy Process (Fuzzy AHP)
An extension of the conventional AHP method that incorporates uncertainty and ambiguity in expert judgments.

**Key Features:**
- Pairwise comparisons using linguistic judgments.
- Application of Triangular Fuzzy Numbers (TFNs).
- Fuzzy synthetic extent and weight derivation.
- Defuzzification and normalization of criteria weights.

### 3. Shannon's Entropy Method
An objective criteria-weighting technique that determines the relative importance of criteria based on the information contained in the dataset.

**Key Features:**
- Data normalization.
- Calculation of entropy values.
- Determination of degree of diversification.
- Derivation of objective criteria weights.

## 📖 How to Use

1. Visit the [Spatial MCDM Tools Homepage](https://dpintu240.github.io/mcdm-calculator/).
2. Select your preferred weighting method: AHP, Fuzzy AHP, or Entropy.
3. Enter the required pairwise comparison values or criteria dataset.
4. Run the calculation to obtain criteria weights.
5. Review the calculated results and use the weights in your spatial modeling workflow.

The resulting criteria weights can be incorporated into GIS-based analysis using software and platforms such as **ArcGIS, QGIS, and Google Earth Engine (GEE)**.

## 🎯 Project Objective

The primary objective of this project is to develop an accessible and user-friendly computational platform for determining criteria weights using established MCDM techniques. It aims to facilitate geospatial research, improve the efficiency of weighting procedures, and support GIS-based multi-criteria decision analysis.
